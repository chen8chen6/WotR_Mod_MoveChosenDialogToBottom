# WotR_Mod_MoveChosenDialogToBottom

	Move previously chosen dialog choices to bottom, s.t. users only need to tap key "1" to continue most of dialogs.
	
	To prevent users from killing NPC unintentionally, choices of evil shifting, attacking NPC, and unrecruiting companion are also moved to bottom.

# Installation:

Method 1:

1. Create a new folder named "MoveChosenDialogToBottom" under the game mod folder(ex: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\Mods\).

2. Unzip the files of "MoveChosenDialogToBottom.zip" into the folder you just created.


-- OR --


Method 2:

1. Download and install the UnityModManager

2. Start UnityModManager. Select "Pathfinder: Wrath of the Righteous" for game label. Select game installtion path(ex: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\) for folder label. Click "Install" button.

3. Click "Mods" label on top, then click "Install Mods" button. Select "MoveChosenDialogToBottom.zip".

# WotR_Mod_MoveChosenDialogToBottom

	已选择的对话选项移动到末尾, 只需要一直按"1"就能推进大部分对话.
	
	为防止用户手快误杀NPC, 邪恶选项, 攻击NPC选项, 解雇队友选项也一并移动到末尾.

# 安装:

方法1:

1. 在游戏mod目录(例: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\Mods\)下创建新文件夹, 命名为MoveChosenDialogToBottom

2. 将压缩包内文件解压到该目录下.


-- 或者 --


方法2:

1. 下载并安装UnityModManager.

2. 启动UnityModManager, Game栏选择Pathfinder: Wrath of the Righteous, Folder栏选择游戏安装目录(例: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\), 然后点击"Install"按钮.

3. 点击上方"Mods"标签, 选择"Install Mods", 在弹出的对话框中选择"MoveChosenDialogToBottom.zip"
